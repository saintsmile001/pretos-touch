# Pretos Touch — Master Build Brief

## 1. Project

Build a production-ready, SEO-first ecommerce website for **Pretos Touch**, a Nigerian consumer brand selling women's wellness, postpartum support, baby care, bras/shapewear, and personal-care products.

The website must be:
- Mobile-first
- Fast
- Accessible
- Trustworthy
- Conversion-focused
- SEO-first
- Social-media friendly
- Easy to expand as the catalog grows
- Designed for Nigerian customers first, with room for wider African/global expansion

Do not build a generic template store. Build a polished, warm, modern consumer brand.

## 2. Current product range

Initial products include:
- Postpartum belt
- Baby electric nail trimmer
- Menstrual belt
- Invisible push-up lift
- Kiss Bra

Treat these as initial catalog examples. The architecture must support many future products without redesigning the site.

## 3. Brand positioning

Core idea:

> Pretos Touch helps women and families feel more comfortable, confident, cared for, and prepared through thoughtfully selected everyday wellness and care products.

Brand attributes:
- Caring
- Modern
- Feminine without being overly decorative
- Trustworthy
- Practical
- Accessible
- Confidence-building
- Customer-first

Avoid:
- Medical-looking branding
- Overly clinical language
- Cheap-looking ecommerce aesthetics
- Excessive pink/purple clichés
- Unsupported medical promises
- Aggressive sales language

## 4. Primary audience

### Audience A — Women/mothers
Interested in:
- Postpartum recovery/support
- Period comfort
- Bras
- Shapewear
- Personal care
- Confidence and comfort

### Audience B — Parents/caregivers
Interested in:
- Baby grooming
- Safe/easy baby-care tools
- Practical products

### Audience C — Social-commerce shoppers
Discover products through:
- Instagram
- TikTok
- Facebook
- WhatsApp
- Influencers/UGC

They need:
- Strong product visuals
- Simple explanations
- Trust signals
- Reviews
- Clear pricing
- Easy ordering
- Mobile-friendly checkout/WhatsApp

## 5. Primary conversion actions

Every important page should make the next action obvious.

Primary:
- Add to cart
- Buy now
- Checkout

Secondary:
- Order via WhatsApp
- View product details
- Read reviews
- Explore related products
- Join email/SMS/WhatsApp marketing where legally appropriate

## 10. Trust

Build trust throughout the site:
- Customer reviews
- Product ratings
- Secure checkout messaging
- Clear delivery information
- Clear returns policy
- Contact details
- WhatsApp support
- Real product photography
- Customer-generated content when available
- Transparent product information

Do not fabricate:
- Reviews
- Certifications
- Awards
- Customer counts
- Delivery promises
- Medical claims
- Stock scarcity

Use placeholders clearly labeled for content that the owner must supply.

## 11. SEO philosophy

SEO must be part of the architecture, not added at the end.

Each indexable page needs:
- Unique title
- Unique meta description
- Canonical URL
- One clear H1
- Logical H2/H3 structure
- Descriptive URL
- Internal links
- Optimized images
- Breadcrumbs where appropriate
- Structured data where applicable
- Useful, original copy

Target Nigerian search intent first, while avoiding keyword stuffing.

## 12. Technical quality

The implementation should prioritize:
- Core Web Vitals
- Responsive design
- Semantic HTML
- Keyboard accessibility
- Good color contrast
- Lazy-loaded non-critical images
- Modern image formats
- Proper image dimensions
- Minimal JavaScript where possible
- Stable layouts
- Error handling
- Loading states
- Empty states
- 404 page
- Form validation

## 13. Content safety

Products involving postpartum or menstrual wellness must not make unsupported medical claims.

Prefer:
- "designed to provide support"
- "may help with comfort"
- "for everyday use"

Avoid claims such as:
- "guarantees healing"
- "cures"
- "reverses"
- "clinically proven" unless verified and documented

## 14. Build principle

When requirements conflict, prioritize in this order:

1. Customer trust and safety
2. Usability/conversion
3. SEO quality
4. Performance
5. Visual polish
6. Convenience for implementation

Do not sacrifice accessibility, performance, or SEO for visual effects.
