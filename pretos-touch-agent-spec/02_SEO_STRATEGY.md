# Pretos Touch — SEO Strategy

## SEO objective

Build Pretos Touch into a searchable Nigerian ecommerce brand with strong commercial, transactional, informational, and local-intent visibility.

SEO must focus on useful pages rather than generating large numbers of thin pages.

## Search intent mapping

Every important keyword should map to ONE primary page.

Example:

| Search intent | Page |
|---|---|
| postpartum belt Nigeria | Postpartum category |
| buy postpartum belt | Product/category |
| how to use postpartum belt | Blog |
| baby electric nail trimmer | Product |
| baby grooming products | Baby Care category |
| invisible push up bra | Product/category |
| menstrual belt | Product/category |

Do not make multiple pages compete for the exact same intent.

## Product SEO template

Title pattern:

`[Product Name] | Pretos Touch`

For high-intent local terms, use naturally:

`[Product Name] in Nigeria | Pretos Touch`

Meta description:
- Explain the product
- Mention key benefit
- Include relevant location when natural
- Include a CTA
- Keep concise

## Structured data

Implement appropriate structured data for:
- Product
- Offer
- AggregateRating/Review only when genuine review data exists
- BreadcrumbList
- Organization
- WebSite
- Article/BlogPosting

Do not generate fake ratings or reviews.

## Canonicals

Every indexable page should have a self-referencing canonical unless there is a deliberate canonical target.

Do not allow:
- Tracking parameters
- Sort parameters
- Filter parameters
- Duplicate pagination
to create uncontrolled SEO duplication.

## Robots and sitemap

Generate:
- XML sitemap
- robots.txt

Include indexable canonical pages in the sitemap.

Exclude:
- Cart
- Checkout
- Account
- Internal search results
- Utility pages that should not rank

## Image SEO

Every meaningful product image needs:
- Descriptive filename
- Useful alt text
- Correct dimensions
- Modern format when supported
- Responsive sizing

Avoid keyword stuffing alt text.

Bad:
`best-postpartum-belt-postpartum-belt-nigeria-best-belt.jpg`

Better:
`pretos-touch-postpartum-support-belt.jpg`

Alt:
`Pretos Touch postpartum support belt`

## Internal links

Use descriptive anchor text.

Bad:
- "Click here"

Better:
- "Explore postpartum support products"

## Local SEO

Use Nigeria naturally in:
- Relevant titles
- Category copy
- Contact page
- Shipping page
- About page
- Product availability messaging

If Pretos Touch has a physical location, create a dedicated location/contact experience with accurate business information.

Never create fake city landing pages.

## Search Console readiness

The build should make it easy to connect:
- Google Search Console
- Google Analytics
- Google Merchant/Shopping ecosystem where applicable
- Meta Pixel
- TikTok Pixel

Keep analytics/pixel integrations modular.

## SEO acceptance criteria

Before launch:
- No accidental noindex on important pages
- No broken canonical URLs
- Sitemap works
- robots.txt works
- Every product has unique metadata
- Images have useful alt text
- Structured data validates
- Internal links work
- 404 page exists
- Redirect strategy exists for changed URLs
- Mobile rendering is good
